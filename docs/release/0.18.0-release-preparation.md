## Publication boundary

This work creates no release tag, registry publication or production deployment. The
earlier cancelled beta [run 40142567511](https://github.com/tokentimerch/tokentimer-core/actions/runs/40142567511)
had already pushed and signed four images before cancellation; Helm OCI and
GitHub release publication had no executed steps. Those preexisting registry

record the resulting release commit and its unchanged product/package source
relationship, and use a separately authorized release operation. Freshly
rebuilt publication artifacts need their own observed digests and gates; do
not substitute the prepared archive's checksum for different bytes.

and restores normal CI to its original main/master trigger. Their executed
definitions remain in the immutable preparation commits. Final documentation
and workflow retirement do not change the accepted product or reusable
acceptance tools.
