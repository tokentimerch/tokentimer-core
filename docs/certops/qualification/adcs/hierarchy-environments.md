# Hierarchy Windows and display-language environments

The manual hierarchy workflow accepts Windows Server 2019, 2022 and 2025, each
with actual English, German or French UI resources. Defaults remain Server 2022
and English. Each dispatch creates one isolated four-VM lab, with the existing
protected environment, main-reference restriction, explicit four/eight-hour
resource lifetime and unconditional owned cleanup. It does not launch nine labs
automatically.

Release qualification requires separate reports for all nine selected member
environments. The same native hierarchy suite runs in each: offline root,
enterprise subordinate, installed SYSTEM agent, actual public issuance, native
chain validation, CNG/IIS/TLS, safety, HTTP intermediate revocation and browser
journeys. The fixture independently checks the member's actual Windows build,
server product type and display language; an input label cannot qualify another
environment. Selection source hashes are mandatory in each report.

The workflow and matrix are executable source coverage. All nine native runs
remain pending until the protected workflow produces valid candidate-bound
reports. The standalone offline root remains the existing fixed appliance;
these version cells describe the Windows member. The enterprise CA and offline
root retain their existing Server 2022 appliances; the selected UI language is
installed and checked on the member and enterprise CA. Independent CA/root OS
cross-products are not qualified by these cells.
