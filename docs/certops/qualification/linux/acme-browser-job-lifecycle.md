# Browser-triggered native ACME job lifecycle

The source actor uses the supported Jobs page's **Create manual job** dialog for agent ACME issuance and stored-profile renewal. It fills the real form, cancels once with zero CertOps writes and unchanged job inventory, then confirms one exact public request. It registers the returned owned job immediately and independently checks the actual database operation, API source and certificate identity. It never intercepts a response or substitutes an executor.

Renewal supplies only the supported reason field; execution settings come from the existing certificate's stored profile. This does not add AD CS first issuance, controller renewal or a generic cancellation route. Cancelling the form before submission is distinct from cancelling an executing certificate operation.

The lifecycle actor retains the actual pinned BrowserServer child and a sticky native-operation guard before launch. It independently checks both completed jobs' actual claim, requesting actor, assigned native agent, stored active certificate and claim-bound verification fingerprint. Each genuine deployed certificate must match its protected private key and a separate trusted TLS connection. Renewal must keep the certificate ID while changing the leaf, serial and public key. Both native generations and actual browser closure must succeed before guard release.

The dedicated `certops-acme-browser-lifecycle.yml` manual workflow runs only trusted `main` on a disposable Ubuntu 24.04 host with certbot and no EAB. It builds the real dashboard and uses the existing real CA/agent journey. The UI issue is the initial native generation; the UI renewal follows the journey's independently verified automated renewals. The parent retains the existing intervening checks and compares the UI renewal to its immediate predecessor as well as the actor's original UI-issued leaf. The separate read-only console lane retains its zero-write contract.

Strict release collection requires the dedicated authenticated workflow, exact measured environment, full closed proof and all current causal source fingerprints. Only the bounded final report is uploaded. Source and pure validation are implemented; protected native execution remains pending. No browser, provider or native certificate operations have been executed for this tranche.
