# Certificate execution across operator signing-key rotation

This proposed native composition remains a source draft. The isolated native noop/pin-rotation suite already covers operator begin, incomplete-fleet refusal, real heartbeat acknowledgements, completion and restart. It does not establish completion of a certificate mutation admitted under the retiring key.

The bounded extension must run in a separate disposable Ubuntu certbot/no-EAB API/PostgreSQL/Pebble stack. It must prove that the deployment-global active agent fleet contains only its exact owned native agent. It must never retire another fixture's agents or rotate a shared database to satisfy that prerequisite.

An actual public renewal is held at the owned native command barrier only after the production agent has verified its original signed claim. A read-only observer records the job and signing-key IDs from the unmodified original version-two envelope; it does not verify the signature or establish execution. Actual current-claim state and the consumed dispatch nonce independently establish production admission. Operator rotation must then begin, receive the real heartbeat pin acknowledgement and complete without force before the original certificate command is released.

Both that original job and a subsequent new-key signed job must produce actual CA-issued leaves, matching local keys, independently trusted served TLS, current-claim verification evidence and a single attempt. The existing execution key-rotation policy must be respected. Configuration and credentials remain unchanged; the signing pin intentionally changes to the authenticated replacement. Original native command drainage, exact protocol-file identities and sticky cleanup authority must protect database and private state on every uncertain failure.

The read-only response observer and pure controls are present. The native producer, separate invocation/workflow, strict report projection and mandatory cell are not yet wired. No native signing rotation, agent, CA, provider, browser or workflow execution has been performed for this draft.
