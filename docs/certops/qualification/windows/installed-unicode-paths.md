# Installed Windows agent with Unicode and literal path characters

This source variant runs the existing real Windows registration and public,
signed ACME issuance journey from an exclusively created temporary installer
root containing spaces, `é`, and literal `[literal]` brackets. The installer
adapter changes only the owned install root. It does not move registered state.
The canonical default-root installer qualification remains a separate scope.

The independent native observation decodes the actual SCM command and live
child command with `CommandLineToArgvW`. It requires the exact installed native
host, Node executable, entry script, service state directory, SYSTEM identities,
and host-child relationship. The external Node executable keeps its real
existing path; this test does not claim it was installed under the Unicode root.
Installed host and entry bytes must match the extracted candidate package.

The proof also requires the actual signed issuance job to succeed on that same
registered service agent, persisted result evidence, protected native CNG
custody, the real IIS binding and independently trusted TLS. Public proof omits
native process identifiers, command lines, paths and credentials. Existing
journey ownership and cleanup guards apply; a replaced root invalidates its
original file-identity receipt.

When historical source upgrade is selected, a separate ASCII-root supporting
subrun first registers the verified historical build and performs the genuine
candidate migration. It stops immediately after that migration and completes
owned cleanup before the full Unicode journey starts with a fresh service,
agent identity and state. Its source-upgrade report is retained under
`qualification-results/historical-supporting-rsa-2048/`. Historical installer
bytes are not patched to add new path behavior. This supporting subrun cannot
satisfy the Unicode path proof, which remains required for every normal Windows
profile cell. The SYSTEM task budget allows 26 minutes for the native test,
28 minutes for its producer and 32 minutes for the task, within the existing
45 minute job limit.

The installer uses literal filesystem paths when reading package/configuration
files, detecting upgrades and removing application or rollback directories.
An ordinary temporary-file regression extracts the actual production staging,
upgrade detection and uninstall filesystem branches from its PowerShell AST.
It checks literal bracket paths and preserves a wildcard-lookalike sibling;
it never runs service or certificate commands.

The helper and supporting adversarial tests are source coverage. Native Windows
execution and release qualification remain pending until the complete producer
and report integration runs successfully in its declared matrix environments.
